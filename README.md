# Quantitative Portfolio Optimization

Python notebooks implementing advanced portfolio construction, asset allocation, and risk-based optimization techniques.

## Methods included

- Hierarchical Risk Parity (HRP)
- Nested Clustered Optimization (NCO)
- Black-Litterman
- Risk Parity
- Conditional Value at Risk (CVaR)
- Conditional Drawdown at Risk (CDaR)
- Mean-Variance-Skewness-Kurtosis (MVSK)
- Maximum Diversification
- Inverse / risk-based portfolio construction
- Robust portfolio optimization
- Discrete allocation
- HRP vs NCO comparison
- Multifactor HRP

The repository is designed as a practical collection of quantitative portfolio optimization implementations in Python.
